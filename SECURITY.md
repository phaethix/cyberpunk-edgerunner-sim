# Security Policy

## Supported Versions

The latest release on the `main` branch is supported with security fixes.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public issue**.

Instead, report it privately by one of the following means:

- Opening a [GitHub security advisory](https://github.com/phaethix/cyberpunk-edgerunner-sim/security/advisories/new)
  (preferred), or
- Emailing the maintainer directly (see the profile linked from the repository).

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce or a proof of concept
- Any suggested mitigation, if known

We will acknowledge your report as soon as possible and keep you informed of
progress toward a fix. Credit will be given (with your permission) in the
release notes.

This project is a game/simulation and does not currently offer a bug-bounty
program.
